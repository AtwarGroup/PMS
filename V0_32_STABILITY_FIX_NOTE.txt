ATWAR ONE V0.32 — STABILITY FIX
================================

تم إصلاح مشكلتين ظهرتا بعد V0.31:

1) صفحة المهام
سبب الخطأ:
تم حذف pageSubtitle من الهيدر القديم، بينما منطق المهام كان يكتب فيه مباشرة.

المعالجة:
- إعادة عنصر pageSubtitle كعنصر Compatibility داخل الهيدر الموحد.
- جعل عملية الكتابة عليه Defensive حتى لا تنهار الصفحة إذا تأخر تحميل الهيدر.
- مراجعة جميع getElementById داخل صفحة المهام آلياً مقابل عناصر DOM المتوفرة.

2) ملفي الوظيفي
المعالجة:
- فرض Shell موحد بشكل صريح حول React root.
- Sidebar + Header من نفس المصدر المركزي.
- إزالة/إخفاء Chrome القديم الخاص بصفحة المدير المالي.
- إبقاء محتوى الملف الوظيفي الاحترافي نفسه.

لم تتم إضافة أي Feature جديدة.
لم يتم تغيير Firebase أو بيانات المهام أو Workflow.
