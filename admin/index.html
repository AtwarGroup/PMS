إدارة النظام

بوابة إدارة الحسابات والمحتوى والمهام وإعدادات النظام.

مكتبة النماذج والأدلة

إدارة النماذج والسجلات والتقارير وقوائم التحقق وربطها بالأوصاف الوظيفية دون تكرار.

لوحة الإعلانات

إنشاء الإعلانات ونشرها للموظفين أو المدراء أو الجميع وتحديد مدة ظهورها.

مكتبة الوظائف

رفع الأوصاف كمسودات، إسنادها للمدير المباشر، متابعة المراجعة والاعتماد ثم النشر للموظفين.

إدارة الحسابات والصلاحيات

إضافة وتعديل المستخدمين، المسمى الوظيفي، الإدارة، الدور، المدير المباشر وحالة الحساب.

إدارة المهام

الوصول إلى جميع المهام والمؤشرات وإعادة فتح المهام المكتملة عند الحاجة.

الهيكل الإداري

مراجعة العلاقات الإدارية والمديرين والموظفين الواقعين تحت كل مستوى إداري.

صحة النظام والصيانة

مراقبة الأخطاء والبريد، استعادة المهام المحذوفة، ومراجعة سجل الحركات الإدارية.
