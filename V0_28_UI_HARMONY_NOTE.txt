ATWAR ONE V0.28 — UI HARMONY
=============================

تم تصحيح الاختلاف بين صفحة المهام وبقية الصفحات.

المعيار الموحد:
- Sidebar desktop: 160px
- نفس التدرج اللوني
- نفس حجم اسم ATWAR ONE
- نفس أحجام أيقونات القائمة
- نفس ارتفاع عناصر القائمة
- نفس Typography للقائمة
- نفس Active state
- Header الرئيسي أصبح أكثر Compact في الصفحات المشتركة

صفحة المهام:
تم تعديل CSS الخاص بالغلاف البصري فقط.
لم يتم تغيير Firebase أو منطق المهام أو البيانات أو Functions.

الهدف:
جميع صفحات ATWAR ONE تبدو كنظام واحد وليس أنظمة منفصلة.
