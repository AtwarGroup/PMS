دليل استخدام ATWAR ONE

مرجع مختصر وعملي يوضح أهم وظائف النظام ودورة المهام والصلاحيات الأساسية لجميع المستخدمين.

المرحلة التجريبية: يتم تطوير وتحسين النظام بشكل مستمر. أي ملاحظة أو خطأ أو اقتراح يتم مشاركته مع إدارة النظام لمراجعته ومعالجته ضمن التطوير اليومي.
الدخول الرئيسية المهام الاعتماد البحث والإشعارات مساحة عملي الفريق والملف الصلاحيات إدارة النظام

الدخول إلى النظام

تسجيل الدخولاستخدم بيانات الحساب المخصصة لك. بعد الدخول يعرض النظام الوظائف والمهام حسب دورك وهيكلك الإداري.
تسجيل الخروجاستخدم خيار تسجيل الخروج عند الانتهاء، خصوصًا إذا كنت تستخدم جهازًا مشتركًا.

الصفحة الرئيسية

تعطيك الصفحة الرئيسية ملخصًا سريعًا للعمل الحالي بدون الحاجة للدخول إلى تفاصيل المهام.

المؤشراتتوضح المهام المكتملة والمفتوحة والمتأخرة، ويظهر «بانتظار اعتمادي» عند وجود مهام تحتاج قرارك.
المحتوى الشخصيتعرض مهامي اليوم، آخر ملاحظة شخصية، والأعمال التي تحتاج انتباهك وفق نطاق الحساب.
يمكن الضغط على مؤشرات المهام للانتقال مباشرة إلى صفحة المهام بالنطاق المناسب.

دورة المهمة

1. إنشاءعنوان، مسؤول، تواريخ، أولوية ووصف.
2. تنفيذبدء العمل وتحديث الإنجاز والملاحظات.
3. اعتمادإرسال المهمة بعد الانتهاء للمدير.
4. قرار المديراعتماد أو إعادة للتصحيح.
5. إغلاقتصبح مكتملة ومقفلة.

أثناء التنفيذ

  • حدّث نسبة الإنجاز والملاحظات كلما تقدم العمل.
  • عند استخدام مهام فرعية يتم احتساب نسبة الإنجاز منها.
  • يمكن تغيير المسؤول فقط ضمن الصلاحيات المتاحة لك.
  • الوصول إلى 100% لا يغلق المهمة تلقائيًا؛ الإغلاق يتم عبر الاعتماد.

الاعتماد وإعادة فتح المهمة

إرسال للاعتمادعند انتهاء التنفيذ تتحول المهمة إلى «بانتظار الاعتماد»، ويتوقف احتساب التأخير عند وقت الإرسال.
قرار المديرالمدير المباشر يستطيع اعتماد المهمة أو إعادتها للتصحيح مع ملاحظة.
المهمة المكتملةبعد الاعتماد تصبح المهمة مكتملة ومقفلة ولا يمكن تعديلها كأي مهمة مفتوحة.
إعادة الفتحمدير النظام فقط يستطيع إعادة فتح مهمة مكتملة، مع تسجيل سبب إعادة الفتح.

الفلاتر والبحث والإشعارات

الفلاتر والبحثاستخدم الحالة، المسؤول، الترتيب والبحث للوصول بسرعة إلى المهام المطلوبة.
الإشعاراتتعرض الإسناد والتحديثات وطلبات الاعتماد وملاحظات المدير. الضغط على الإشعار المرتبط بمهمة يفتح المهمة مباشرة متى كانت ضمن صلاحيتك.
إذا لم تظهر مهمة تتوقع رؤيتها، تحقق أولًا من الفلاتر الحالية ومن نطاق صلاحيتك.

مساحة عملي

مساحة شخصية مساندة للعمل، وتحفظ بياناتها في قاعدة البيانات تحت حساب المستخدم.

ملاحظاتيلتسجيل معلومة أو تذكير شخصي سريع والعودة إليه لاحقًا.
متابعاتيلمتابعة موضوع يحتاج استكمالًا أو رجوعًا في وقت لاحق.
الملاحظات والمتابعات تبقى محفوظة عند تسجيل الخروج وعند الدخول من جهاز أو متصفح آخر.

الفريق والهيكل والملف الوظيفي

فريقي والهيكلللمديرين، ويعرض الموظفين الواقعين تحت مسؤوليتهم حسب المدير المباشر والتسلسل الإداري المعتمد.
الملف الوظيفيإذا تم تجهيز ملف الموظف يظهر داخل النظام. وإذا لم يجهز بعد تظهر رسالة «الملف الوظيفي تحت الإنشاء».
إذا كان هناك خطأ في المدير المباشر أو الإدارة، تتم مشاركته مع إدارة النظام لتصحيح الهيكل.

الصلاحيات

الموظف

يدير مهامه ومساحة عمله ويحدث التنفيذ ويرسل المهمة للاعتماد.

المدير

يتابع فريقه ومهامه، ويعتمد مهام مرؤوسيه المباشرين أو يعيدها للتصحيح.

مدير النظام

يدير الحسابات والصلاحيات وله نطاق إداري أوسع، وهو الوحيد الذي يستطيع إعادة فتح المهمة المكتملة.

إدارة النظام

قسم خاص بمدير النظام لإدارة الحسابات ومراجعة الأدوار والصلاحيات. عند إضافة أو تعديل مستخدم يجب التأكد من الاسم والبريد والمسمى والإدارة والدور والمدير المباشر.

لا تستخدم صلاحيات مدير النظام لإجراء تغييرات غير معتمدة على الحسابات أو الهيكل الإداري.

عند وجود ملاحظة أو مشكلة

شارك الملاحظة مع إدارة النظام، ويفضل ذكر الصفحة والخطوة التي قمت بها وإرفاق صورة للشاشة عند الحاجة. سيتم مراجعة الملاحظات ومعالجتها ضمن عملية التطوير المستمرة.
