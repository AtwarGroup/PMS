دليل نظام المهام

مرجع مختصر لاستخدام المهام في ATWAR ONE وفق دورة العمل والصلاحيات المعتمدة حاليًا.

دورة المهمة

1. إنشاء المهمة: يتم تحديد المسؤول وتاريخ البداية والنهاية والأولوية والتفاصيل المطلوبة.
2. التنفيذ: الموظف يحدث نسبة الإنجاز والملاحظات حتى اكتمال العمل.
3. إرسال للاعتماد: عند إنهاء العمل تتحول المهمة إلى بانتظار الاعتماد ويتوقف احتساب التأخير عند وقت الإرسال.
4. قرار المدير: المدير المباشر يعتمد المهمة فتتحول إلى مكتملة، أو يعيدها للعمل مع ملاحظة.
5. بعد الإكمال: المهمة المكتملة مقفلة، ولا يمكن إعادة فتحها إلا بواسطة مدير النظام مع تسجيل سبب إعادة الفتح.

الفلاتر والبحث

استخدم «الكل، اليوم، متأخرة، قيد التنفيذ، مكتملة» مع فلتر المسؤول والترتيب. البحث العام يفتح المهمة المرتبطة مباشرة عندما تكون ضمن نطاق صلاحيتك.

الصلاحيات

الموظف يرى مهامه. المدير يرى مهامه وكامل الشجرة الإدارية الواقعة تحت مسؤوليته، بينما الاعتماد يبقى للمدير المباشر. مدير النظام لديه نطاق النظام وإمكانية إعادة فتح المهمة المكتملة.
